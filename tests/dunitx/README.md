# NativePe DUnitX suite

## Scope

The suite combines deterministic NativePe regressions, non-destructive Windows integration tests, and an exact libpeconv-fidelity layer based on the libpeconv test archive.

Current inventory:

- 272 tests
- 36 fixtures
- original libpeconv binary fixtures with SHA-256 preflight verification
- full byte-for-byte copies of the original 32-bit and 64-bit shellcode arrays
- Debug and Release configurations
- NUnit XML output
- console log output
- Debug range checking enabled
- Debug integer-overflow checking enabled

The robustness expansion includes narrowly scoped parser hardening where new malformed fixtures exposed concrete correctness issues in resources and exports.

## Robustness matrix

`NativePe.Robustness.Tests.pas` adds deterministic coverage for exception-directory structure and bounds, RAW/virtual section-layout edge cases, multi-root and malformed resources, export holes/ordinals/forwarders, a broader malformed-PE matrix, and PE32/PE32+ RAW -> virtual -> RAW -> virtual semantic roundtrips. Runtime exception-table registration remains isolated in the RealWorld runner because it mutates process-wide state.

## Exact reference fixtures

The repository includes under `tests\dunitx\fixtures\libpeconv` the exact files from the libpeconv test archive that are needed by the fidelity tests:

- `greek_to_me.bin`
- `payload.dll`
- `test_case3_32.exe`
- `test_case3_64.exe`
- `shellc32.bin`
- `shellc64.bin`

The first four are copied directly from the libpeconv test archive. The shellcode `.bin` files are generated byte-for-byte from `shellc32.h` and `shellc64.h`. Their complete arrays are also embedded as Delphi constants and compared byte-for-byte by DUnitX.

## Install

Overlay the package on the NativePe repository root. The test package primarily lives under `tests\dunitx`; this robustness delta also updates the directly affected parser units under `src`.

Open `tests\dunitx\NativePeDUnitX.dproj`.

## Run

Debug:

```bat
scripts\run-nativepe-dunitx.bat Debug
```

Release:

```bat
scripts\run-nativepe-dunitx.bat Release
```

Both:

```bat
scripts\run-nativepe-dunitx-all.bat
```

Before DUnitX starts, `verify-libpeconv-fixtures.bat` verifies all libpeconv fixture SHA-256 values. A modified or wrong fixture aborts the run.

Results:

- `test-results\NativePeDUnitX-Debug.xml`
- `test-results\NativePeDUnitX-Debug.log`
- `test-results\NativePeDUnitX-Release.xml`
- `test-results\NativePeDUnitX-Release.log`

## Fidelity policy

Tests are labelled precisely in `LIBPECONV-TEST-MATRIX.md` as exact-fixture, exact-byte, direct behavioral port, source-faithful synthetic, or opt-in. The suite does not claim exact binary parity when the original compiled fixture is absent from the libpeconv test archive.

The ordinary runner deliberately does not execute the reference payloads or process-wide exception-table tests. Those belong in a separate opt-in integration process.
